# MC Security Reporter

Public release mirror. Changes are developed and tested in the private system repository, then exported by the release workflow. Do not edit mirrored plugin files directly. No private repository history, system config, inventory or credentials are published.

Current plugin source version: 0.2.3. Install the attached release ZIP rather than GitHub source archives. Use native WordPress updates after the initial installation of version 0.2.0 or later. Automatic installation follows the site's WordPress settings and hosting policy. SHA-256 verifies package integrity against this channel; it does not protect against a compromised publishing account.

Read readme.txt for scope, privacy and update-service details. Project code licensing remains an owner decision; no WordPress.org directory publication is implied.
